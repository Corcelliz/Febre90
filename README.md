# Febre90's

Site da dupla de rap **Febre90's** (SonoTWS × PumaPJL). HTML, CSS e JS puros, sem build.

## Páginas
- `index.html` — home: hero, lançamentos, a dupla, player, links
- `piscar.html` — matéria "No Piscar dos Olhos" (MPSCB001)
- `sementinha.html` — matéria "Sementinha do Mal" (MPSCB003)

## Rodar localmente
```
python -m http.server 8000
```
Abra http://localhost:8000

## Identidade
Fanzine/gibi de rua: papel creme, tinta preta e as cores do letreiro.
Tokens em `:root` no topo de `assets/css/style.css`. Fontes: Bowlby One, Source Serif 4, Space Mono (Google Fonts).
